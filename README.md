# Automação TCENET

Automação de rotinas de cadastro no sistema TCENET utilizando Python e Selenium.

## Objetivo

Automatizar etapas operacionais do cadastro de admissões, reduzindo tarefas manuais e tornando o processo mais organizado.

## Tecnologias utilizadas

- Python
- Selenium WebDriver
- Google Chrome
- OpenPyXL

## Estrutura do projeto

```text
Automacao-TCENET/
├── main.py
├── Selenium_base.py
└── app/
    ├── interface.py
    ├── automacao.py
    ├── controle.py
    ├── config.py
    └── planilha.py
```

*Observação: a estrutura acima é ilustrativa e deve corresponder aos arquivos efetivamente presentes no repositório.*

## Requisitos

- Python instalado
- Google Chrome instalado
- Dependências Python do projeto
- Acesso autorizado ao sistema TCENET
- Acesso às planilhas e aos diretórios de rede necessários à execução

## Configuração

1. Configure os caminhos das planilhas e dos diretórios necessários no ambiente autorizado.
2. Instale as dependências Python utilizadas pelo projeto.
3. Confira as configurações do Chrome e do Selenium.
4. Execute `main.py` para iniciar a automação.

## Segurança

Este projeto pode depender de sistemas internos, arquivos de rede e dados administrativos. Não publique senhas, credenciais, dados pessoais ou documentos restritos.
